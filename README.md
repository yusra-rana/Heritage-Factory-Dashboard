# 🏭 Heritage Factory Dashboard

A Full Stack Manufacturing Management Dashboard built with **Node.js**, **Express.js**, **HTML**, **CSS**, and **JavaScript**.

## ✨ Features

- 🔐 Secure JWT Authentication
- 🔑 bcrypt Password Hashing
- 📊 Dashboard Overview
- 📦 Orders Management (CRUD)
- 🏭 Production Management
- 📦 Inventory Management
- 👨‍💼 Employee Management
- 🚚 Supplier Management
- 🧭 Sidebar Navigation
- 📱 Responsive Design
- 💾 Persistent JSON Data Storage

## 🛠️ Tech Stack

- HTML5
- CSS3
- JavaScript (ES6)
- Node.js
- Express.js
- JWT
- bcrypt
